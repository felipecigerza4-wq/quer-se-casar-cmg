# Pedido de Casamento — "quer-se-casar-cmg"

Este repositório contém um site simples de pedido de casamento com fogos de artifício em canvas, um botão "SIM" que dispara os fogos e tenta usar SpeechSynthesis para dizer "Eu te amo, Naty", e um botão "NÃO" que "foge" quando você tenta clicar.

URL do repositório: https://github.com/felipecigerza4-wq/quer-se-casar-cmg

Como ver localmente

1. Clone o repositório ou baixe/abra `index.html` localmente.
2. Abra `index.html` no Google Chrome (arraste para a aba ou use Ctrl+O).
3. Se o navegador bloquear o áudio automático, clique no botão "Ouvir & Iniciar" que aparece.

Publicar com GitHub Pages

1. Abra as configurações do repositório: Settings → Pages.
2. Em "Source" escolha a branch `main` e `/ (root)` como pasta. Salve.
3. Aguarde alguns minutos. A URL provável será: `https://felipecigerza4-wq.github.io/quer-se-casar-cmg`

Observações

- Navegadores podem bloquear autoplay de áudio. O site tenta falar automaticamente, mas se isso falhar o botão na sobreposição permitirá ativar o áudio.
- Não consigo abrir o Google Chrome na sua máquina ou forçar o navegador a reproduzir áudio remotamente — o site está preparado para fazer isso quando for aberto.

Se quiser, posso:

- Modificar o texto falado (atualmente: "Eu te amo, Naty").
- Adicionar um som de fogos ou música de fundo (posso incluir um arquivo de áudio ou instruções para hospedá-lo).
- Habilitar o Pages automaticamente (posso fornecer instruções passo-a-passo) — eu não tenho permissões para alterar as Settings → Pages via esta ferramenta.
